# Critical Ops Public API Wrappers

This repository includes wrappers for the [Critical Ops Public API](https://criticalopsgame.com/api/), including:
- JavaScript
- TypeScript
- Python (soon)
- ...

# Implementation

This wrapper implements all the endpoints of the public api.
- Profiles
- Weapon Stats
- Autohost
- Server Status
- Leaderboards
- Match History

# Unix Timestamps

All the unix timestamps in the public api are in seconds, never in milliseconds.
